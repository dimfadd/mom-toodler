# Font Nexa Pro

Nexa Pro adalah font berbayar dari Fontfabric. Setelah membeli lisensi web, taruh file berikut di folder ini:

- `NexaPro-Regular.woff2` (400, teks biasa)
- `NexaPro-Bold.woff2` (700, judul dan tombol)
- `NexaPro-Heavy.woff2` (800, angka besar)

Nama file harus persis sama. Setelah itu build ulang (`npm run build`) atau push ke GitHub supaya Vercel deploy ulang. Selama file belum ada, situs memakai Montserrat.
